# ALADDIN Lab website

Next.js (App Router) static site for GitHub Pages. Content lives in `data/*.yaml`; publications come from ORCID.

## Run locally
```bash
npm install
npm run sync:orcid   # optional: pull publications from ORCID + Crossref
npm run dev          # http://localhost:3000
npm run build        # static site -> out/
```

## Where to edit
| File | Controls |
|---|---|
| `data/site.yaml` | Name, tagline, affiliations, contact, ORCID iD, topic tags (+ keywords) |
| `data/research.yaml` | Research sections, Key papers (by DOI), figures |
| `data/team.yaml` | Team (`group`: pi / member / alumni), photos in `public/images/team/` |
| `data/news.yaml` | Home page news |
| `data/publication-meta.yaml` | Per-paper `tags`, `selected`, `figure`, `hidden` (keyed by DOI) |
| `data/publications-manual.yaml` | Papers without a DOI |
| `data/publications.json` | Generated by `sync:orcid`; do not edit by hand |

Papers are tagged automatically by the keyword rules in `data/site.yaml`; add `tags` in `publication-meta.yaml` to set them explicitly.

## Deploy (GitHub Pages)
1. Create the repo, push to `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Project site (`https://<user>.github.io/<repo>`): set repository variable `BASE_PATH` = `/<repo>`.
   Custom domain (e.g. `aladdin-labs.ai`) or `<user>.github.io` repo: leave `BASE_PATH` unset.
4. Custom domain: add `public/CNAME` containing the domain, then set the DNS records in Pages settings.
5. `Sync publications from ORCID` runs weekly (and on demand) and commits `data/publications.json`, which triggers a redeploy.
